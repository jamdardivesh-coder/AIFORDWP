Resolved. Cause: DESKTOP-FB099 carried a legacy manual MDM enrolment from 2023-11-04 that was not removed before a Windows Autopilot enrolment was attempted on 2024-03-15. Autopilot failed at the enrolment stage with error 0x80180014 ("The device is already enrolled in MDM"), preventing all four assigned policy profiles from applying and blocking compliance evaluation. Licensing and network reachability were confirmed not causal. Action: Delete the stale managed device record from Intune admin center (Devices > All devices), disconnect the legacy work or school connection from the device (Settings > Accounts > Access work or school), restart, reset to OOBE, and rerun Autopilot while preserving the valid Windows Autopilot device registration; verify by confirming a new managed device object checks in, applied profile count exceeds zero, and compliance evaluation completes. Preventive: Add a mandatory pre-Autopilot preflight check to the rebuild runbook requiring confirmation that no legacy MDM managed device record exists in Intune and no obsolete work or school connection remains on the endpoint before Autopilot is started; flag previously manually enrolled devices in the asset workflow so cleanup is enforced before redeployment. User notified; device reprovisioning in progress under INC-2024-0315-AUTOPILOT-FB099.
