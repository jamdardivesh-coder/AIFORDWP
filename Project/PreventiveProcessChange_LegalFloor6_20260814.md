Issue 2 (Widespread Login Failures / Very Slow Logon) - Mandatory Next-Business-Day Logon Gate (NBDLG): for any Legal Floor 6 deployment that affects logon/startup behavior, Change Management must require pilot-ring validation at first business-day login before broad-release closure, with pass criteria of normal logon performance (exact metric thresholds to confirm), and automatic hold/rollback if the pilot exceeds threshold.

Issue 3 (Desktop Shortcuts Missing Post-Rollout) - Mandatory Shortcut Baseline Integrity Check (SBIC): before and after Floor 6 rollout closure, Endpoint Engineering must run an automated desktop/start-menu baseline comparison for the approved shortcut set across pilot devices, with pass criteria of zero unauthorized removals (allowed exception list and sampling size to confirm), and automatic hold/remediation if any required shortcut is missing.
